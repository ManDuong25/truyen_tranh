# Local Environment and Research Artifacts

This file records the local-only parts of the workspace that are intentionally
not committed to git. A fresh agent should use this document to rebuild the
same practical development environment after cloning the repository.

## Baseline

- Repository: `https://github.com/ManDuong25/truyen_tranh.git`
- Main branch: `main`
- Last known pushed commit at documentation time: `b1bb8b1 first commit`
- Local OS used for the first setup: Windows PowerShell

- OpenCode used for LLM smoke tests: `opencode 1.2.27`

virtual environment is still recommended so future dependencies do not leak

## Harness CLI

The Harness CLI binary under `scripts/bin/` is ignored because it is a generated
platform-specific binary. After cloning, reinstall or refresh Harness in merge
mode to download the Windows CLI again:

```powershell
& ([scriptblock]::Create((irm "https://raw.githubusercontent.com/hoangnb24/repository-harness/main/scripts/install-harness.ps1"))) -Merge -Yes
.\scripts\bin\harness-cli.exe query matrix
```

`harness.db` is also local-only. It stores local Harness durable records such as
trace rows. The durable project knowledge that agents should inherit is kept in
versioned markdown files under `docs/`, especially `docs/product/`,
`docs/stories/`, and `docs/decisions/`.

If an agent needs the exact local Harness trace database, copy `harness.db`
from the original workspace out-of-band. Do not commit it.

| `__pycache__/`, `*.pyc` | Python cache files. | Regenerated by Python. |
